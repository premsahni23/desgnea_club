Desgnea Club × ASD — static website

This package is ready for static hosting. Upload the contents of this folder into your Hostinger public_html directory. The home page is index.html.

To connect the Register Now buttons, open config.js and paste your complete application-form URL between the quotes:
window.DESGNEA_CLUB_APPLICATION_FORM_URL = "https://...";

The same setting controls the desktop header, mobile menu and hero buttons. Until the URL is set, those buttons show a clear message instead of sending visitors to a broken link.

All logo, background and font assets are included. The page has no external dependencies.
